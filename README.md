# 🧭 AI Navigation Assistant for the Visually Impaired

An AI-powered navigation assistant built using **YOLOv8**, **OpenCV**, and **Streamlit** to help visually impaired individuals detect and recognize surrounding objects in real time.

---

# 🚀 Features

* ✅ Real-time object detection
* ✅ Multi-object tracking
* ✅ Webcam support
* ✅ Streamlit web interface
* ✅ Adjustable confidence threshold
* ✅ YOLOv8 deep learning model

---

# 🛠️ Tech Stack

* Python
* YOLOv8 (Ultralytics)
* OpenCV
* Streamlit
* PyTorch

# ⚙️ Installation

```bash
git clone https://github.com/keshav-o0o/Navigation-Assistant-for-the-Visually-Impaired-using-CNN-2025.git

cd "Navigation Assistant"

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python -m streamlit run app.py
```
